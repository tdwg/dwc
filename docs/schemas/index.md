## 1 Introduction

The Darwin Core Maintenance Group manages a collection of schemas used to support the exchange of biodiversity data through Darwin Core Archives (DwC-A) and Darwin Core Data Packages (DwC-DP).
These schemas are non-normative components of the Darwin Core standard. They are implementation resources maintained by the Darwin Core Maintenance Group to ensure they remain aligned with term definitions and the Darwin Core Conceptual Model as those evolve. The schemas are used by a range of applications, including the GBIF Integrated Publishing Toolkit (IPT), which supports the publication of datasets compliant with the Darwin Core Text Guide or the Darwin Core Data Package Guide.

### 1.1 Status of the content of this document

All sections of this document are non-normative (explanatory).

## 2 Audience

This document is targeted toward those who want to share biodiversity information using Darwin Core Archives (DwC-A) or Darwin Core Data Packages (DwC-DP). It points to the schemas officially maintained by the Darwin Core Maintenance Group for this purpose.

## 3 DwC-A table schemas

The DwC-A schemas provide the terms suitable for mapping data against "core" and "extension" tables. All tables linked in the subsections of this section are considered to be non-normative parts of the Darwin Core Standard. Following are DwC-A schemas currently managed by the DwC Maintenance Group.

### 3.1 DwC-A core tables

- Occurrence (2026-05-26)
- Event (2026-05-26)
- Taxon (2026-05-26)

### 3.2 DwC-A extension tables

- Measurement Or Facts (2026-05-26)
- Resource Relationship (2026-05-26)
- Chronometric Age (2026-05-26)
- Humboldt Ecological Inventory (2026-05-26)
- Identification History (2026-05-26)
- DNA Derived Data (2023-06-01)

## 4 DwC-DP profiles and table schemas
